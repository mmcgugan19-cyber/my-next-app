Phase 3 — Prepare the Affidavit
GATE

MAJOR BRANCHING POINT

Does the state require court filing?

Some states let you handle everything out-of-court. Others require filing with the probate court (Summary Administration).

Path A — Out-of-Court

No court filing required
  • Draft Small Estate Affidavit (state-specific form)
  • Fill in estate details, values, heir info
  • Attach copy of will (if exists)
  • Get affidavit notarized
  • Keep notarized original — this is your authority
Collect: notarization date

Path B — Court Filing

Summary Administration required
  • Draft Small Estate Affidavit (state-specific form)
  • Fill in estate details, values, heir info
  • Attach copy of will (if exists)
  • File affidavit with Probate Court
  • Pay filing fee
  • Receive court order / Certificate of Transfer
  • Order 3–5 certified copies of court order
Collect: filing date Collect: court order date Collect: filing fee amount

Phase 5 — Settle Debts (Concurrent with Phase 4)

Phase 5 — Settle Debts

Pay what's owed before distributing to heirs
  • Notify each known creditor of the death (in writing)
  • Pay in priority order: funeral → medical → taxes → secured → unsecured
  • Keep receipts and records of every payment

BRANCHING POINT

Do debts exceed assets?

If the estate owes more than it owns, the distribution rules change significantly.
INSOLVENT ESTATE

Debts > Assets

Estate cannot pay all debts. User is not personally liable (usually), but distribution is blocked. Recommend attorney consultation for priority payment guidance.

Solvent — Debts Paid

All known debts settled. Remaining assets available for distribution to heirs.
Phase 6 — Distribute to Heirs
GATE

All Assets Collected + All Debts Settled

BRANCHING POINT

Will or Intestacy?

Determines who receives what and in what proportion.

With Will

Distribute per will terms
  • Calculate remaining estate value
  • Distribute to each named beneficiary
  • Get signed receipt from each person
  • Keep copies of all distribution records

Without Will (Intestacy)

Distribute per state law
  • Calculate remaining estate value
  • Determine shares per state intestacy rules
  • Distribute to each legal heir
  • Get signed receipt from each person
  • Keep copies of all distribution records
Phase 7 — Close Out

Phase 7 — Close Out

Final administrative wrap-up
  • File deceased's final federal income tax return
  • File deceased's final state income tax return
  • File estate income tax return (if estate earned income)
  • Cancel remaining subscriptions and memberships
  • Close email and social media accounts
  • Forward mail via USPS
  • Notify credit bureaus to prevent identity theft
